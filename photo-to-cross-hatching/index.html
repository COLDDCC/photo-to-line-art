What this cross-hatching converter does

Cross-hatching builds dark areas from two sets of intersecting lines. In this converter, the first layer follows the image’s light and dark values. A second layer appears in darker regions. That makes shaded faces, rocky slopes and dark objects read as line-based images rather than blocks of flat grey. The result is produced by a deterministic browser algorithm, not a generative AI model.

Choose a photo with readable shadows

Start with a clear subject and a background that does not compete with it. A well-lit portrait, a still life or a landscape with distinct sunlit and shaded areas is a useful starting point. Tiny foliage, image noise and patterned clothing can produce dense strokes. If a photo looks crowded, reduce density or contrast before increasing line width.

Adjust density before thickness

The controls change different parts of the drawing. Density changes the spacing between lines. Width changes the amount of ink in each stroke. Contrast changes which image values become more strongly shaded. Try the Classic preset first, reduce density if the drawing fills in, then adjust width to suit the size you will use. Select Cross-hatching under More settings to return to this page’s default line direction.

Download and print within the image’s resolution

PNG output has a longest side of up to 2000 pixels and does not enlarge small originals. It is a raster image, not a vector or plotter path. For a print, check the pixel dimensions against the physical size you need: 2000 pixels at 300 pixels per inch is about 6.7 inches. A lower print density can support a larger print, with less fine detail.

Cross-hatching is different from outline tracing

This tool describes tone with lines. It does not remove the background automatically, trace a continuous contour, or turn the picture into a closed-shape coloring page. For a sparser landscape interpretation, try the minimalist mode. The original photograph and the output remain separate so you can judge how much detail the strokes retain.
